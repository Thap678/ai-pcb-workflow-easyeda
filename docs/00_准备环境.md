# 00 准备环境

全部在 Windows 上实测；其他系统没试过（easyeda-agent 和 EDA 客户端本身跨平台，Freerouting 的解包步骤不同）。

| 组件 | 版本 | 用途 |
|---|---|---|
| 嘉立创EDA 专业版（EasyEDA Pro） | V4.1.60（4.0.0 以上） | 原理图和 PCB 本体；文件夹工程（.eprj3）和数据库工程（.eprj2）都能用 |
| easyeda-agent（CLI + daemon + EDA 扩展） | v1.8.1 | 让脚本/agent 读写 EDA：放元件、连线、导入、布局、DRC、导出 |
| Python | 3.11+（用到 tomllib） | `pip install -r requirements.txt`（shapely、numpy、scipy、Pillow） |
| Freerouting | 2.5.0 **Java 版**（Windows MSI） | 自动布线 |
| Node.js（可选） | 22.15+ | 只有 `kit/recover/dsh_dump.js` 要用 |

## easyeda-agent

1. 安装 CLI 和 EDA 扩展（按 easyeda-agent 的发行说明），确认 `easyeda version` 输出 v1.8.x。
2. **daemon 必须常驻**：`easyeda daemon start` 放在一个单独的终端或后台运行。没起时 `easyeda health` 全部 unreachable。
3. 打开嘉立创EDA 和工程。`easyeda health` 里 `windows` 列表不能为空；为空就重载 easyeda-agent 扩展或重启 EDA。
4. EDA 窗口重连后 windowId 会变；脚本统一用 `--project <工程 UUID>` 路由，不依赖 windowId。

## Freerouting 2.5.0

- 从 Freerouting 的 GitHub Releases 下载 `freerouting-2.5.0-windows-x64.msi`（88,718,425 字节），
  SHA-256 应为 `f5144acbeefa53248a0e0f2078a13600be73710bb386c013ee11cf0aa9cc10fb`。
  放到本仓库 `freerouting/` 下，`tools/check_env.py` 会自动校验（该目录已在 .gitignore 里）。
- **只解包、不安装**，而且目标目录必须是纯英文路径（中文路径 msiexec 报 1603/1708）：
  ```
  msiexec /a freerouting-2.5.0-windows-x64.msi /qn TARGETDIR=C:\fr_extract
  ```
  得到 `C:\fr_extract\freerouting\freerouting.exe`（自带 Java 运行时）。别的位置就在配置 `[route] freerouting` 里写路径，或设环境变量 `FR_EXE`。
- **不要用原生的 freerouting-cli**：遇到禁布区会崩，多轮之间也会崩。
- 运行时总是加 `--usage_and_diagnostic_data.disable_analytics=true`（`route.py` 已加）。

## 检查

```bash
python tools/check_env.py
```

全部 OK 再开始。带配置时（当前目录有 `board.toml` 或用 `--cfg`），它还会确认配置里的工程就是 EDA 里打开的那个。
