# 04 PCB 导入与布局

## 1. 导入、板框、规则

```bash
easyeda --project <P> --doc <PCB> pcb import-changes     # 原理图 -> PCB（多板就每块各做一次）
python kit/pcb/outline.py                                 # 圆角矩形板框 + 安装孔（board.toml 的尺寸/孔位）
python kit/pcb/rules.py                                   # 设计规则 + 电源/地线宽规则，并分配到网络
```

- 板框要在布局、布线之前定好；铺铜后再改板框，铜会悬空。
- `rules.py` 以板上当前规则为模板写入，结构永远和你的 EDA 版本一致；`--dry-run` 只生成 JSON 不写入。
- 网络 → 线宽规则的分配走的是 `eda.pcb_Drc.overwriteNetRules`（CLI 的 drc-rules-set 不带这部分）。脚本最后会读回核对。

## 2. 布局方法

按这个顺序摆，每一步摆完就锁定：

1. **机械定死的件**：叠板连接器（上下板必须对齐，坐标从对方板推算）、核心板插座、安装位附近的件、面板上的按键/旋钮/屏幕、板边接口（朝外插拔）。
2. **按功能分区**：电源区、MCU 区、传感/接口区、射频区（射频模块天线下方禁铜）。分区边界顺着信号流向。
3. **小件**：去耦电容贴着对应芯片的电源脚（< 3 mm）；上拉/串阻靠近被拉的那一端；指示灯和测试点不要被模块挡住。

把坐标写成表（模板 [templates/placement.example.csv](../templates/placement.example.csv)，坐标是元件外框**中心**，单位 mm，原点板左下角）：

```bash
python kit/pcb/place_table.py placement.csv          # 摆放 + 锁定 + 检查
python kit/pcb/place_table.py placement.csv --check-only
```

脚本会报告：中心偏离表格、超出板框、压到安装孔禁布区、同面元件外框重叠（外框含丝印，重叠项要人看一眼）。

已有一份布局快照时（例如重建工程、或复制工程到新版本）：

```bash
python kit/pcb/place_from_dump.py layout_snapshot.json     # 按位号恢复坐标、角度、正反面、锁定
```

## 3. 两个要先核对的地方

- **封装焊盘**：嘉立创库里的封装会更新。同一个料号，这次和上次的焊盘可能不一样大（示例的测试点 RH-5015 从 1×1 mm 变成 2.8×1.5 mm，2.5 mm 间距下三个焊盘叠在一起，整板布不通）。布局后、布线前，看一眼密集处的焊盘尺寸和间距。
- **正反面**：底面元件在 EDA 里是镜像的。底面的排针、按键要按镜像后的引脚位置核对。

## 4. 交给用户

出一张布局图（`python kit/dump.py layout.json` 后 `python kit/route/render.py --dump layout.json --out layout.png`），让用户确认：接口朝向、操作件位置、核心板/模块的方向、丝印是否会被挡住。用户微调后，以 EDA 里的实际布局为准（`kit/dump.py` 存一份快照）。

## 过关标准

- 无出界、无压安装孔；重叠项人工确认过；
- 密集处焊盘无重叠；
- 用户看过布局图并确认。
