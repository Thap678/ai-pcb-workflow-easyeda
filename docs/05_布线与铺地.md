# 05 布线与铺地

**原则：EDA 不进调参循环。** 布线、打分、出图全部离线完成，只把选中的那一版导入 EDA 做正式核对。这样一版只要几分钟，可以并行跑很多版。

## 1. 导出与预处理

```bash
python kit/backup.py before-route
easyeda --project <P> --doc <PCB> pcb export-dsn --name board.dsn    # 文件在当前目录的 .easyeda/artifacts/
python kit/route/prep_dsn.py .easyeda/artifacts/<时间>-pcb_dsn-*.dsn prep.dsn
```

`prep_dsn.py` 修正 EasyEDA 导出的 DSN，否则 Freerouting 的结果导入后过不了 DRC：

| 问题 | 处理 |
|---|---|
| 网络类成员带单引号，Freerouting 不认，电源线宽失效 | 去引号 |
| 布线间距 = 规则最小值，导入后 EDA 的 DRC 会差一点点 | 布线间距提高一档（默认 0.2 mm，规则 0.15） |
| 安装孔导出成「裸孔径」焊盘，线会贴着孔走 | 放大到「孔半径 + slot_pour_mm − 布线间距」 |
| 定位柱/固定脚这类无网络孔，EDA 规则要求离槽 0.3 mm | 放大「slot_copper_mm − 布线间距」 |
| 板边 | 布线边界内缩 0.15 mm |

注意：同一形状的焊盘在 DSN 里共用一个定义。**只放大「只被无网络引脚用到」的定义**——排针的 NC 脚和接了网络的脚共用一个定义，放大了会让整排排针焊盘变大，相邻焊盘之间穿不过线（这个坑让示例整板剩 15 条布不通）。

## 2. 并行布线

在 board.toml 里写几个参数版本（`[[boards.<板>.route.variants]]`），然后：

```bash
python kit/route/route.py prep.dsn
```

输出排名（未布线 → 违规 → 过孔数）。参数含义：

| 参数 | 作用 | 经验值 |
|---|---|---|
| `via` | 过孔代价 | 默认 50。**低于 50 过孔暴增**（10/25/40 都试过）；70 过孔最少，但长斜线变多 |
| `bot` = [顺向, 逆向] | 底层走线代价 | 3.5/4.5 让信号少走底层，底层地平面更完整（地面评分大涨的主要来源） |
| `top_dir` / `bot_dir` | 层的优选方向 | **跟着主要走线方向走**：示例小车板两层 horizontal 最好；25×63 mm 的竖长板（排针总线竖走）两层都 vertical 比都 horizontal 少 21% 过孔、短 4% |
| `edge_clearance_um` | 铜到板边（环境变量注入） | 450 可布通；600 以上剩若干条布不通 |
| `passes` | 布线轮数 | 100 |

**从已布线的板子重新导出时**：DSN 里旧的过孔会作为固定焊盘出现、旧走线在 `(wiring)` 里标成 protect。`prep_dsn.py` 现在会去掉它们（输出里会写 `old routing dropped`）；之前没去掉时，Freerouting 是绕着旧过孔、甚至借用旧过孔在布，同一配方的过孔数会被低估一大截。

Freerouting 2.5.0 **没有**直角、长斜线、过孔对齐网格的参数（DSN 里的 `bend_cost`、`grid via` 被忽略，实测过），这些交给后处理。

**调参方法**：一次只改一个维度，每批 4–10 个版本并行；先 `batch_score.py --batch route_runs/<板>` 离线打分排名（写 ranking.md），再把前三名的图（`render.py --dsn prep.dsn --batch route_runs/<板> --top 3`，按排名出图和拼图）给用户看，给 2–3 个下一步方向让用户选（例如「压过孔」「让底层更干净」「停，取第一名」）。示例跑了 7 轮约 70 版才定下 r9-02 配方；有了配方之后，重建只需要一轮 4 版。

**全部版本都布不通时，先别调参**：
- 日志里有 `pre-existing clearance violation`：输入里焊盘已经重叠（封装或布局问题），回阶段 4。
- 没有预存违规但剩十几条：对比原始导出和 prep 后的焊盘尺寸，看是不是预处理误放大了。

## 3. 检查、后处理、导入

```bash
python kit/route/ses_conn.py prep.dsn route_runs/<板>/<id>/out.ses       # 路由器输出：0 open nets
python kit/route/ses_polish.py route_runs/<板>/<id>/out.ses --dsn prep.dsn --chamfer 0 --out final.ses
python kit/route/ses_conn.py prep.dsn final.ses                          # 后处理后仍 0 open nets
python kit/route/apply_ses.py final.ses
```

`ses_polish.py` 离线改写走线（每处改动都先做几何间距校验，不合格就撤回）：统一线宽、推离板边和安装孔、平行线等距成股、过孔吸附 0.5 mm 栅格（孔距 ≥ 0.8 mm）、可选倒角（`--chamfer 0.25`）。

`apply_ses.py`：删铺铜 → 拆线 → 导入 SES → **恢复线宽**（EDA 导入时会把每根线改成网络规则默认宽度）→ 存盘 → 读回连通检查。

导入后常见的两类 DRC（Physical Error），各有一个脚本：

```bash
python kit/dump.py imported.json
python kit/route/fix_widths.py imported.json <导入的.ses> --min-only --apply   # Freerouting 在密脚处收窄到 4.4 mil：只加宽到规则最小值
python kit/route/fix_vias.py --apply                                           # 导入的过孔孔径 7.8 mil < 规则 7.9：按规则尺寸重建（带读回）
```

`ses_polish.py` 的统一线宽会把电源线整段加宽，在 0.5 mm 间距的 QFN 旁边可能新增间距不足；导入前用独立间距检查确认，或者直接导入原始 SES。

## 4. 铺地、缝合、核对

```bash
python kit/route/pour_gnd.py                    # 两面 GND 铺铜（内缩 0.3 mm）
python kit/dump.py poured.json
python kit/route/stitch.py poured.json          # 缝合孔：死铜岛各补一个 + 4 mm 网格；避开焊盘；重建铺铜并存盘
easyeda --project <P> doc reload <PCB>
easyeda --project <P> --doc <PCB> pcb drc --json --timeout 300 > drc.json
python kit/route/drcsum.py drc.json             # passed True total 0
python kit/dump.py final.json
python kit/route/conn.py final.json             # nets with unrouted connections: 0
python kit/route/gmetrics.py final.json final   # 地面评分
python kit/route/render.py --dump final.json --out board.png
python kit/backup.py routed
```

DRC 里剩下的个别问题（例如某个缝合孔离焊盘差 0.01 mm）：`easyeda ... pcb via-delete --ids <id>`，然后 `pour-rebuild`、存盘、reload、再跑 DRC。

## 5. CLI 自带的 route-short / beautify：只经守护脚本用

这两个命令原地改铜，失败了不回滚（easyeda-agent v1.8.1、EasyEDA Pro 4.1.60 实测）：

- `pcb route-short`（issue #5）：L 形走线会压到异网焊盘（0 mil 短路），线宽也不按网络规则；这样的种子 Freerouting 会报 `pre-existing clearance violation`，接不下去。
- `pcb beautify`（issue #4）：整板 902 段时超时（`context deadline exceeded`），但已经删了一半线，留下 243 处断开。

确实要用时：

```bash
python kit/pcb/guard.py route-short --corner 45 --width-signal 6 --dry-run   # 只看保留/丢弃哪些跳线
python kit/pcb/guard.py route-short --corner 45 --width-signal 6
python kit/pcb/guard.py beautify --net USB_DP --net USB_DN                   # 不给 --net 就是全部网络
python kit/pcb/guard.py restore-copper guard_runs/<板>/<时间>_beautify/before.json   # 撤销 / 中途断开后恢复
```

- `route-short`：取命令自己的 dry-run 计划，按「焊盘到焊盘」拆成跳线；把线宽补到网络规则最小值，离异网铜（焊盘、已有走线、过孔、已保留的跳线）不到间距规则、或离板边太近的跳线直接丢掉，留给 Freerouting；剩下的自己逐段画、读回、重铺铜、跑 DRC，仍有间距/物理违规的网络把新线删掉。强制 `--no-multilayer`（计划里没有过孔坐标，无法核对）。
- `beautify`：按网络分批（每批不超过 `--max-tracks` 段，默认 60），每批一个调用，不会碰到连接器超时；每批后读回、查连通，断了的网络立刻按快照恢复；最后重铺铜跑 DRC，比原来多出违规的网络也恢复。
- `restore-copper`：把指定网络（默认：和快照不一样的所有网络）的走线、圆弧、过孔恢复成快照里的样子。比「拆线后重导 SES」快，也不需要 SES。

两点实测行为，自己写脚本时也要注意：
- **EDA 会合并共线的同网走线**：同网、同层、同宽、首尾相接又共线的两段，连续创建时会被合成一段（两次创建相隔 0.3 s 就会）。按「一段对一段」读回核对会误判为缺两段、多一段——守护脚本先把共线段合并再比较。
- **`doc reload` 后铺铜可能是旧的**：`pour-rebuild` → 存盘 → `doc reload` → DRC，报过新线与 GND 铺铜 0 mil；`pour-rebuild` 后直接 DRC 是对的。而且 `doc reload` 是「存盘 + 关闭 + 重开」，连接器负载高时重开会超时，PCB 标签页就没了，之后所有命令都失败，要手动重新打开 PCB。

## 6. 实验过、对这块板没用的路子（别再重复）

ESP32-S3 DevKitC 复刻板（25×63 mm，2 层，44 件）上试过，结论如下，换板子时可以再试：

| 做法 | 结果 |
|---|---|
| 模组到排针的 37 根线用 `(circuit (use_layer TopLayer))` 限定在顶层 | 排针旁通道在 LDO/二极管/模组焊盘处太窄，14–48 根布不通 |
| GND 用 Freerouting 的 `(plane ...)` | EasyEDA 的 DSN 下 Freerouting 认为「没有 SMD 引脚、0 条要布」，输出空 |
| GND 不走线：从网表删掉 GND，布完后 `gnd_fanout.py` 给每个 GND 焊盘加短线+过孔，两面铺铜 | 信号线在板中部把两层铺铜都横向切断，`pour_sim.py` 估算地分成 5–7 块，缝合孔也接不上 |
| 线下布局搜索（飞线交叉 + 长度做代价，模拟退火，候选再用 Freerouting 实布） | 不加约束能到 77 过孔，但会把去耦电容、ESD 管挪离引脚 3 mm；加上约束后 83–88，和不动布局（89）差不多，在 Freerouting 的随机波动内 |

`kit/route/gnd_fanout.py`（GND 焊盘扇出）和 `kit/route/pour_sim.py`（线下估算两面铺铜能否连通、自动补缝合孔）可以用在铺铜不容易被切断的板子上。

## 7. 成束布线：低速板要「线成束、地成片」时（`route_bundle.py`）

Freerouting 只求线短、孔少，低速板上的结果是孤线散满两层、把铺铜切成碎块。线长不重要的板子（控制板、传感器板）可以改用自研的成束布线器：从引脚重新布全部信号网，**贴着已有走线走便宜、走空地贵**，线自己聚成等距的束，空出来的地方整块留给铺铜。电源（宽线）沿用一份已布好的 SES，GND 不走线（每个贴片 GND 焊盘先打扇出孔，两面铺铜接起来）。

```bash
# 1. 用 Freerouting 布一版，只为拿电源走法（--maxw 以上的网会原样保留）；GND 从网表删掉再布更好
python kit/route/route_bundle.py prep.dsn route_runs/<板>/<id>/out.ses bundle.ses        # ~15 min，需 numba
python kit/route/ses_smooth.py prep.dsn bundle.ses bundle_s.ses                          # 拉直网格锯齿，20k -> 3k 段
python kit/route/ses_check.py prep.dsn bundle_s.ses                                      # 0 间距违规、0 断网
# 2. 导入：只重画变了的网，其余不动
python kit/dump.py live.json
python kit/pcb/ses2target.py live.json <现板对应的.ses> bundle_s.ses target.json
python kit/pcb/guard.py restore-copper target.json
python kit/dump.py after.json && python kit/pcb/cover_check.py target.json after.json miss.json   # 逐段核对
# 3. 铺铜规则改直连（见下）→ pour-rebuild → DRC → 剩下的 GND 孤岛：
python kit/route/gnd_tie.py prep.dsn poured.json bundle_s.ses tied.ses [--drop x,y]
python kit/pcb/ses2target.py poured.json bundle_s.ses tied.ses target_gnd.json
python kit/pcb/guard.py restore-copper target_gnd.json --net GND
```

代价（每 mm）：顶层 `1 + OPEN·min(d−dmin, D)/D`（d = 到最近异网走线的距离），底层 `BOT × 同样的贴线系数`，每个过孔 `VIA`，45° 转角 0.25、90° 0.8、更尖不允许。网格 0.05 mm 上做 A*（状态 = 层 × 格 × 朝向）；间距是硬约束（异网铜按布线间距 + 半线宽外扩），每个网布完再用 shapely 精确校验；布不通时允许穿过已布的线找路，把挡路的网拆掉重排（被拆越多次越贵）；最后整板就位后每个网再布一次（polish），过孔不多于原来才换。

nuedc-car-2026 上板（80×87 mm，81 个信号网）的调参：

| 底层 / 过孔代价 | 信号+电源过孔 | 底层最大整块地 | 结论 |
|---|---|---|---|
| Freerouting（现板） | 140 | 3379 mm² | 孤线多，底层 13 块 |
| 10 / 8 | 280–450 | 5150–5230 mm² | 底层接近整块，但孔太多（短跳线一对对地钻） |
| **1.5 / 25，底层也贴线，polish 1（默认）** | **175** | **4279 mm²** | 孔数接近 Freerouting，两层都成束 |
| 1.5 / 40、1 / 60 | 177、150 | 3371、1853 mm² | 孔不再少，底层被长线切碎 |

库里这版（另加了过孔避让通孔焊盘的孔距）用默认参数复跑：81/81 布通，过孔 192，底层最大整块 4319 mm²，`ses_check.py` 0 违规 0 断网。

导入 EDA 后（直连铺铜）：底层最大整块 3831 → 4762 mm²，死铜 0，地面评分 91 → 129.6；DRC 只剩 2 个被两层走线围死的插座 GND 脚。

要点和坑：
- **过孔多的根因是短跳线，不是底层代价本身**：顶层贴线会绕着线束走，每遇一次交叉就钻下去一对孔。过孔要贵（≈ 25 mm 顶层线），底层要便宜，下去了就多走一段。
- **拉直要限偏离**：`ses_smooth.py` 不限偏离时抄近路离开线束，底层最大整块 −7%；`--dev 0.15` 时指标不变。
- **铺铜连接改直连**：花焊盘（发散）要有地方放辐条，被线束围住的焊盘就连不上——死铜 32 块、GND 岛 43 个；改直连（Plane › Copper Zone 里 `multiLayerPadModel` / `singleLayerPadModel` 的 `connectMode` 0 → 1）后 0 块、2 个。代价是插件 GND 焊盘手焊要多加热。
- **扇出孔要避开通孔焊盘的孔**：同网 GND 孔贴着 GND 排针脚，铜间距不查，但 DRC 查孔距（19.7 mil）。`route_bundle.py` / `gnd_tie.py` 已按 `hole_to_hole_mm` 避让。
- `conn.py` 只认端点相接，会把「线接在另一根线中段」（本布线器的 T 形接点）报成断开；以 `ses_check.py`（铜重叠口径）和 EDA DRC 为准。
- **布完再挤线没用**：在 Freerouting 结果上做「气球」挤线（线沿法向平移、向邻线靠拢）只换来底层最大整块 +150 mm²——走哪条走廊由过孔位置决定，平移改不了拓扑；只重布过孔之间的顶层段也一样（+80 mm²）。
- **别给碎铜补孔凑面积**：给不接地的碎块各打一个孔，面积 +1600 mm²，但最大整块一点没变、块数翻倍，只是评分好看。`gnd_tie.py` 只接带焊盘的孤岛和成片（≥ `--min-area`）的地。
- EasyEDA 窗口在后台时 `pcb drc` 不返回（画布重算不跑），重试会叠加重算把 EDA 卡死：跑 DRC 前把窗口放前台，只跑一次。

## 8. 四层板 + 内层电源分割（`route_plane.py`）

适用：四层板，**Inner1 整层地、Inner2 按电源分区**（每路电源一整块连通的区域，区间留缝），顶层信号 + 大电流电源铺铜块，底层信号 + 地。电源不能整层铺一种（2026-11-08 用户否决：电机电源噪声铺到逻辑区下面、底层信号拿它当参考面），也不能靠细线连（那一版 3V3 走了 250 mm 线）。同样的成束布线器（第 7 节），但不需要 Freerouting 的结果，从引脚开始全部自己布。

### 先在配置里写分区（`[boards.<板>.planes]`，例子见 `board.example.toml`）

- `regions`：每路电源一组矩形，**按顺序排，前面的优先**（重叠处归前面的），`cut` 挖掉一块。先布局再画分区：所有大电流电源焊盘、插件电源脚都要落在自己的区里；`python kit/route/plane_board.py <dump>` 列出每个区是不是一整块、哪些插件电源脚在区外。
- `pours`：顶层大电流铺铜块，每块一组焊盘（不写 = 该网全部顶层焊盘）。布线器先用 1 mm 线把这组焊盘连起来（骨架），再外扩成铺铜块——块天然连通，也不会吞掉别网焊盘。
- `wide_nets`：先布、不铺铜的宽线（电机输出、采样电阻）。
- `keepout_refs`：电感本体下方顶层 / 底层 / 电源层禁布，地层保留作屏蔽。

### 流程

```bash
python kit/backup.py before-route
python kit/dump.py live.json
python kit/route/plane_board.py live.json                         # 每个区一整块、插件电源脚都在区内
bash kit/route/plane_par.sh live.json route_plane_runs "base:" "dir:--layer-dir"   # 每组一个核，约 30 min
python kit/route/plane_fixup.py live.json route_plane_runs/base.json fixed.json   # 补缝合孔、补地线
python kit/route/plane_render.py live.json fixed.json plane.png   # 给用户看
python kit/route/plane_apply.py live.json fixed.json              # 自动备份 -> 清旧铜 -> 写线/孔/铺铜/禁布区 -> 存盘
python kit/route/plane_drc.py                                     # reload -> 逐网重铺 -> DRC
python kit/route/plane_check.py --netlist --page <原理图页>        # 含实际灌铜的连通、走线风格、层、禁布、网表
```

三个阶段（每一阶段的结果都当作下一阶段的固定铜）：
1. **电源骨架**：铺铜组 + 宽线，1 mm，只走顶层；骨架外扩成铺铜块。
2. **打孔进平面**：电源网的每个贴片焊盘一段短线 + 过孔，孔落在自己的区里；每个贴片地焊盘一个孔到地层；每块铺铜先打 1 个缝合孔。细间距芯片（≥5 个贴片脚、间距 < 0.8 mm）：0.5 mm 短线出不来就换 0.25 mm、必须从自己的脚直着出去；本体下和别的脚往外的「出线道」里不许打孔；还没孔的地脚从本体下直连到同一芯片已有孔的地脚。
3. **信号**：其余网 0.25 mm，顶层 / 底层；落在区外的小电流电源脚（「例外」）按 19 mm 聚类，每簇一棵树接到附近同网的孔。

### 默认参数为什么是这样（nuedc-car-2026 下板：87 个信号网、80×87 mm、实测）

| 做法 | 结果 |
|---|---|
| **网格间距 = `router_clearance_mm`（0.20），精确校验低 0.04，拆线判定不加余量，每块铺铜 1 个缝合孔，GND 不在布线器里补（默认）** | **87/87，33 min**，之后 `plane_fixup.py` 补 27 个缝合孔；写入 EDA 后 DRC 只剩 1 条已核实的 Netlist Error，`plane_check.py` clean |
| 布线器里打满缝合孔（每块最多 8 个） | 底层被孔切碎，拆线不收敛（38–52 个孔时 1 h 停在 75–85/95） |
| 网格间距 0.215、精确校验 = 网格间距 | 贴着固定铜的路径因栅格取整差几 μm，永远过不了校验，也拆不掉 |
| 拆线判定 +0.06 mm | 一根长线一次拆 10–13 根，整板来回震荡 |
| GND 补线放进布线器、目标是「全板任意地孔」 | 每次搜索窗口都是整板，一轮 100 s；补线被拆来拆去 |
| 加权 A*（启发 ×1.5–2） | 用户不采用 |
| 上下层分方向（`--layer-dir`：东西向线底层便宜、南北向顶层） | 结果和随机波动差不多：项目里的第 6–13 轮没帮上；库里这版（加了过孔孔距避让）复跑时它 2688 s 先 87/87，默认那组还在 75–81/87 来回。**两组一起并行跑，谁先通用谁** |

用时主要在 A* 本身（一根 7 个脚跨全板的 CAN_H 一次 37 s），单线程、拆不开核：**多组参数并行**（`plane_par.sh`，每组约 1.5 GB 内存）。

### 布局决定能不能布通

布线器报 `STALL`（同一网被拆 12 次）或 `no path` 时，先看位置，多半是布局问题，不是参数：
- **芯片方向反了**：TPS48111（U201）采样脚背对采样电阻、栅极背对 MOS → 放到背面（镜像后方向正好对）。
- **引脚顺序造成交叉**：IO 扩展上 DIR_R 往东走、却夹在一排往南走的脚中间 → 和另一个脚对调（原理图 + 固件一起改，先问用户）。把芯片翻面只会把交叉换到另一根线上。
- **小件占了出线口**：去耦电容贴着 INA228 的出线侧；上拉电阻放在别的电源区里（离最近同网孔 28 mm）。
- 按飞线拥挤度给布局候选打分只能粗筛：直线飞线穿过电感禁布区、穿过一排焊盘都会被算成拥挤，实际走线会绕开。下板上「U502 翻面」打分略好（76.6 对 77.3），但看引脚就知道交叉只是从 DIR_R 换到了 DIR_L——打分只用来排除明显差的候选，最后以实布为准。

### EasyEDA 侧（写入之后）

- 写入用 JS 批量（`plane_apply.py`），网格路径先合并共线点（13k → 2k 段）。
- **写完要 `doc reload` 再 DRC**：批量建线 / 孔后连通缓存是旧的，DRC 报了 239 条「走线未连接」，其实全通。之后每次通过 API 改线 / 孔 / 器件，也要 reload。
- **铺铜按网重建**：一次重建 22 块铺铜会在连接器上超时；`pcb pour-rebuild --net <网>` 每个几秒。顺序：reload → 逐网重建 → DRC（`plane_drc.py`）。
- **实际灌铜形状**用 `pcb_PrimitivePour.getCopperRegion()` 读（单位 10 mil，`fill: false` 的项是花焊盘辐条），`plane_check.py` 拿它算连通：EDA 的 DRC 既漏报过真孤岛（电源铺铜块没有孔下到电源层），也误报过 239 条。
- 写入后剩下的零星间距（0.198 mm 对 7.9 mil 规则）手修：改走法，不要改线宽——电源网的线宽规则会再报一次。

## 地面评分

`gmetrics.py` 衡量地平面完整度（越高越好）：

```
1.0 × 底层主地覆盖% + 0.5 × 顶层主地覆盖% + 0.4 × 底层最大整块%
+ 0.3 × 两层主地总面积%（铺铜面积加分）− 0.3 ×（底层块数 − 1）− 2 × 死铜岛数 − 0.005 × 底层信号线长 mm
```

示例的历程：自动布线初版 16.2 → 地面优化 53.9 → 换脚优化 55.0 → 批量调参（底层代价 3.5/4.5）81.3 → r9-02 89.8 → 重建版 94.2 → 成束布线 + 直连铺铜 129.6（第 7 节）。

## 过关标准

- DRC 0（只剩 Netlist Error 时：`plane_check.py --netlist` 逐脚核对一致才算过）；
- 两层板：`conn.py` 0 断开、`ses_check.py` 0 违规；分割电源层的四层板：`plane_check.py` 输出 `RESULT: clean`（含实际灌铜的连通、0 条非 45°、0 个直角、内层无走线、电源铺铜块里无信号线、禁布区下无铜）；
- 用户看过成品图。

## 可选的局部优化（布通之后）

- 电源换层处并联 2–4 个过孔（一个 0.3 mm 孔约 1 A）；
- 每个去耦电容的地焊盘 1 mm 内补一个地过孔；
- 窗口重布：把最乱的区域里完全在窗口内的网络拆掉，其余走线固定，只对这个区域再跑几版。
