# 08 备份与恢复

## 备份

```bash
python kit/backup.py <标签>              # 整个工程 -> <backup.dir>/<日期时间>_<标签>.epro2
```

- `backup.dir` 在 board.toml 里配，**必须在工作文件夹之外**（示例放在「文档」目录）。
- 建议节点：原理图建完、布局定稿、每次重布线前、布线完成、出板前。
- `.epro2` 可以在嘉立创EDA 里直接打开/导入，恢复整个工程（原理图、PCB、规则）。
- 工作文件夹建议同时用 git 管理（脚本、规格、配置、文档），工程文件夹本身体积不大，也可以一起提交。

## 工作区丢了怎么办

按顺序试：

1. **回收站**：直接删除的文件夹一般在回收站；用命令行或别的程序删的通常不在。
2. **`.epro2` 备份**：有就直接导入，结束。
3. **从 AI 会话记录恢复文本文件**（脚本、规格、文档）：
   - Claude Code 的记录：`~/.claude/projects/<目录名>/*.jsonl`；改文件前的备份在 `~/.claude/file-history/<会话>/`。
   - 其他 agent（示例里是一个用 zstd 压缩记录的 agent）：`node kit/recover/dsh_dump.js <会话目录> <输出目录>` 先解压成 jsonl。
   - 回放：
     ```bash
     python kit/recover/replay.py --root <丢失的目录> <输出目录> <claude 会话.jsonl ...> -- <其他 agent 的 jsonl ...>
     ```
     按时间顺序回放每一次「写文件 / 编辑 / 完整读取」，还原目标目录下的文件，并生成 `_report.csv`。标 `BROKEN` 的文件中途被命令行改过（记录里看不到），需要人工补那几处。
   - `--root` 填丢失的那个目录的完整路径（记录里的文件路径以它开头的才会还原）。
4. **重建 EDA 工程**：EDA 工程文件（.esch2/.epcb2）一般没法从会话记录恢复。用恢复出来的规格 JSON 和布局快照，按本仓库流程重建：
   原理图 `build_pages.py` → 导入 → `outline.py` + `rules.py` → `place_from_dump.py` → 布线 → 铺地 → 出板。
   示例就是这样一天之内从空工程重建回来的（见 examples/nuedc-car-2026/README.md）。

固态硬盘上被永久删除的文件，通常很快被 TRIM 清掉，用数据恢复软件找回的希望很小，不建议在这上面花时间。
