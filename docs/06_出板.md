# 06 出板

## 1. 导出

```bash
python kit/backup.py before-release
python kit/fab/export.py                     # -> release/<板>_<时间>/
```

导出内容（全部通过 EasyEDA 官方接口 `eda.pcb_ManufactureData` 生成，以 base64 经 `debug exec` 传回再由 Python 写盘——`saveFileToFileSystem` 会拒绝任意路径，非全离线客户端上还被禁用）：

| 文件 | 用途 |
|---|---|
| `<名>_Gerber.zip` | 制板：各层铜、阻焊、钢网、丝印、板框、钻孔 |
| `<名>_PickAndPlace.csv` | 贴片坐标 |
| `<名>_BOM.csv` | 物料清单（含 LCSC 料号列） |
| `<名>_IPC356A` | 裸板电测网表（可选） |
| `<名>_project.epro2` | 整个工程的备份，和这批出板文件对应 |

## 2. 自动检查

```bash
python kit/fab/check.py release/<板>_<时间>
```

生成 `release_check.md`：

| 检查 | FAIL / WARN 的意思 |
|---|---|
| Gerber 层齐全（2 层：顶/底铜、顶/底阻焊、顶丝印、板框、钻孔；4 层再加两层内电层） | 缺层 → FAIL |
| 板框尺寸 = 配置的宽 × 高（±0.5 mm，含线宽） | 不符 → FAIL |
| 钻孔数量、最小孔径 | 0 孔 → FAIL |
| BOM 与坐标文件的位号一致 | 不一致 → WARN |
| BOM 行没有 LCSC 料号（嘉立创不能贴） | WARN：要么补料号，要么接受手焊 |
| 贴片坐标超出板框 | WARN：通常是单位或原点问题 |
| IPC-356 网表、工程备份 | 缺备份 → FAIL |

实测（测试工程，80×87 mm 两层板）：Gerber zip 265 KB，含顶/底铜、顶/底丝印、顶/底阻焊、顶钢网、板框、文档层、钻孔图、PTH/NPTH/过孔三个钻孔文件和飞针测试文件；`check.py` 结果：板框 80.00 × 87.00 mm、607 个钻孔、BOM 90 个位号与坐标文件一致，唯一 WARN 是测试点没有 LCSC 料号（测试点只是焊盘，不需要贴片，属于正常）。

## 3. 下单前人工确认（只能人做）

- 在嘉立创的 Gerber 查看器里打开 zip，逐层看一遍；
- 丝印：位号可读、极性标记（二极管、电解电容、芯片 1 脚）清楚、版本号和日期；
- 下单参数：板厚、铜厚、颜色、表面处理、是否贴片、贴片面；
- 叠板时两块板一起下，核对叠板连接器的公母和高度。

**本工具包不会下单。** EasyEDA 有 `placePcbOrder` / `placeComponentsOrder` 接口，脚本从不调用；下单和付款必须由用户本人在嘉立创完成。

## 过关标准

- `check.py` 无 FAIL；
- WARN 项用户确认过；
- 人工确认清单做完。
