# 03 原理图：规格 JSON → 建图 → 读存盘文件逐脚核对

原理图不是让 AI 在画布上「画」出来的，而是**先写成数据，再由脚本落到 EDA，最后从存盘文件里读回来逐脚比对**。这样每一根连线都有据可查，改动可以重放，出错能精确定位到哪个脚。

## 1. 页面规格 JSON

每个原理图页一份（模板 [templates/page_spec.example.json](../templates/page_spec.example.json)）：

```json
{
 "page": "9c1e217877da67e8",
 "power": ["5V_MAIN", "3V3_MAIN"],
 "ground": ["GND"],
 "parts": [
  {"ref": "U603", "lcsc": "C6186", "x": 540, "y": 720, "rot": 0,
   "nets": {"VIN": "5V_MAIN", "VOUT*": "3V3_MAIN", "GND": "GND"}, "nc": []},
  {"ref": "C604", "lcsc": "C15850", "x": 320, "y": 720, "rot": 90,
   "nets": {"1": "5V_MAIN", "2": "GND"}}
 ]
}
```

| 字段 | 说明 |
|---|---|
| `page` | 原理图页 UUID（`easyeda doc ls`）。`project` 可省，默认取 board.toml |
| `power` / `ground` | 这一页里画成电源符号/地符号的网络；其余网络画成网络标签 |
| `ref` | 位号，全板唯一 |
| `lcsc` 或 `lib`+`uuid` | 器件来源；`uuid` 必须是**器件** UUID |
| `x`, `y`, `rot`, `mirror` | 原理图坐标（EDA 原理图单位，A4 图框内大约 x 150–1130、y 240–785），旋转角度 |
| `nets` | 引脚 → 网络。键可以是引脚号或引脚名；名字后加 `*` 表示所有同名引脚（如 `"GND*"`） |
| `nc` | 不接的引脚号，会打上不连接标记 |

**每个引脚必须出现在 `nets` 或 `nc` 里**，否则 `drv.py connect` 拒绝执行——这样漏接的脚在落图前就会暴露。

## 2. 离线检查

```bash
python kit/sch/check_specs.py specs/main_p1.json specs/main_p2.json ...     # 一块板的全部页
```

报告网络数、**单脚网络**（几乎都是笔误或漏了一个元件）、重复位号、缺料号、同一网络在不同页被声明成电源和信号。`RESULT OK` 才去碰 EDA。

## 3. 建图

```bash
python kit/sch/build_pages.py specs/main_p1.json specs/main_p2.json ...
```

每页依次：

1. **place**：按料号查库、放元件（已存在的位号跳过；连接器会迟到确认，所以失败后会读回再判断，最多重试 4 次）；
2. **connect**：每个引脚引出一小段线接网络标签/电源符号（`sch autoconnect`，自动避开图框和其他引脚）；
3. **nc**：打不连接标记；
4. **save**：存盘；
5. **verify**：`verify_file.py` 读**存盘后的 .esch2 文件**，按导线端点和网络标签算出每个引脚实际连到的网络，和规格逐脚比对。

为什么读文件而不是读接口：`sch list` 回读的 `pin.net` 在部分工程里是空的，不可信；存盘文件是最终真相。

输出 `verify ... N pins checked, 0 problems` 才算这一页完成。单个脚没连上时：

```bash
python kit/sch/drv.py specs/main_p2.json connect Q201     # 只重连这个元件
easyeda --project <P> --doc <页UUID> sch save
```

然后重新核对这一页。

## 4. 改原理图

- 要删元件：`python kit/sch/del_parts.py <页UUID> R601 C601`（先逐脚断线、清不连接标记，再删）。
- 要改连接：改规格 JSON，删掉相关元件后重新 place + connect，或者对单个元件 `drv.py connect <位号>`。
- **用户在 EDA 里手改过的**（换封装、改编号）：读存盘文件或 `sch list` 拿到改动，**并回规格 JSON**，再用 `verify_file.py` 确认两者一致。示例里用户把测试点换成了系统库的 Test-Point-0.5mm 并重编号，就是这样并回 `gen_specC.py` 的。

## 5. 跨页、跨板核对

- `check_specs.py` 按整块板统计网络，跨页的同名网络自动合并。
- 两块板通过叠板连接器相连时，单独写一段检查：上板连接器第 n 脚的网络 = 下板对应脚的网络（底面排针奇偶对调）。示例 `inputs/gen_specC.py` 末尾有这段检查，40 脚逐个比对。

## 过关标准

- 每页 `0 problems`；
- `check_specs.py` 的网络数符合设计、无单脚网络；
- 跨板连接器逐脚核对通过。
