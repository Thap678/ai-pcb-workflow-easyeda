# 01 需求与方案

画板子之前，先把「要什么」写成可核对的文字。AI 在这一阶段的价值是把零散的想法整理成**有数字、有分级、可验证**的需求，并把需要人决定的地方变成选择题。

## 怎么做

1. **收集输入**：用户的目标（比赛题目、产品功能）、旧板子的原理图/PCB、已有的模块和机械结构。旧板是最好的需求来源：逐块分析它们有什么功能、哪些出过问题。
2. **写需求文档**（模板 [templates/requirements.md](../templates/requirements.md)）：
   - 功能逐条编号，分 **P0 必须 / P1 应该 / P2 可选**。每条写清楚验收方法。
   - 机械：板子尺寸、安装孔位置和孔径、叠板方式、接口朝向（从哪一边插拔）、限高。
   - 电源：输入电压范围、每路输出的电压和**最大电流**、保护（防反接、保险丝、TVS）。
   - 接口：每个连接器的型号、针数、针序、对端。
3. **电源方案**：画出电源树（输入 → 各级 DC-DC/LDO → 负载），每个节点写电流预算。线宽和过孔数量都从这里来：1 oz 外层温升约 10 °C 时，3 A 约 1.2 mm，1 A 约 0.5 mm；一个 0.3 mm 孔的过孔按 1 A 左右算。
4. **把决策点变成选择题**：每个需要用户拍板的地方，给 2–3 个选项，标出推荐项和代价，例如：

   > 5V 舵机供电：A（推荐）独立 DC-DC ≥5 A，舵机堵转不拖垮主控，多 ¥6 和 1.5 cm²；B 共用 5V_LOGIC，省面积，堵转时主控可能复位。

5. **逐条确认**：需求文档的版本号随每次确认递增（v0.1 草案 → v1.0 定稿），变更写在文档顶部。

## 过关标准

- 每条 P0/P1 需求都有验收方法；
- 尺寸、孔位、接口朝向、电源树（含电流）已确认；
- 文档末尾的「决策记录」列出了用户的每个选择。

## 经验

- 板子尺寸和孔位一旦变动，布局要整体重来（示例里板子在需求 v0.9 从 80×80 改成 80×87，安装孔随之移动）。尺寸和孔位尽量在需求阶段定死。
- 叠板时，两块板的叠板连接器要从一开始就定好**谁在底面、谁在顶面**：底面排针在 EDA 里是镜像的，原理图里要按「奇偶对调」接（1↔2、3↔4…），这一点必须在原理图阶段就写进规格并逐脚核对。
