# 阶段 4：导入、板框、规则、布局

先读 `pcb-workflow` 技能里的硬规则和协作规矩（本次会话读过就不用再读）。`ROOT` = 本文件所在目录的上两级。
详细方法：`ROOT/docs/04_布局.md`。

布局决定后面能不能布通、布出来好不好看。**宁可在这里多花一轮，也不要带着差布局去布线。**

## 顺序

每一步做完出图给用户看，确认后锁定，再做下一步。

1. **导入、板框、规则**
   ```bash
   python <ROOT>/kit/backup.py before-place
   easyeda --project <P> --doc <PCB> pcb import-changes
   python <ROOT>/kit/pcb/outline.py        # 板框 + 安装孔，来自 board.toml
   python <ROOT>/kit/pcb/rules.py          # 设计规则 + 电源/地线宽规则，写入后读回
   ```
   板框形状先和用户确认（停点 S2）。多块板的安装孔要对齐。
   用户要一份「能直接导入的设计规则文件」时：`rules.py --dry-run` 以板上现有规则为模板生成 JSON，结构和用户的 EDA 版本一致。
2. **大件和机械定死的件**：叠板连接器（坐标从对方板推算）、核心板插座、板边接口、操作件、屏幕、安装孔附近的件。**先只摆这些，然后必须停下来**（停点 S3）：渲染大件布局图发给用户，问意见（接口朝向、操作件位置、模块方向、板框还要不要收），等用户回答后再摆小件。
   这一步可以关：`pcb-workflow` 或项目交接文档的「停点开关」表里把 S3 改成「关」，就不停不问、按推荐布局继续，但图照样生成，决定记进交接文档。
3. **按功能分区摆其余的件**：电源、主控、驱动、传感、接口，分区顺着信号和电流的流向。
4. **小件**：去耦电容贴着电源脚（3 mm 内）；上拉、串阻靠近被拉的一端。
5. **按飞线优化**（见下文），然后才交给布线。

摆放用坐标表（模板 `ROOT/templates/placement.example.csv`）：

```bash
python <ROOT>/kit/pcb/place_table.py placement.csv     # 摆放 + 锁定 + 报告出界、压孔、重叠
python <ROOT>/kit/dump.py layout.json
python <ROOT>/kit/route/render.py --dump layout.json --out layout.png
```

## 用户在意的布局要求

没有相反说明时按这些做：

- **操作件放板边，按「怎么用」来摆。** 旋钮、编码器、五向开关、按键、屏幕是一组：屏幕在眼睛看的位置，旋钮和开关在顺手的一侧，彼此靠近，操作时手不挡屏幕。先问用户怎么拿着板子用，或者要一张参考图；用户给了参考图就照图摆。
- **接口朝外**，从板边插拔，线不跨过板子。同类接口排在一起。
- **板子能小则小。** 摆完后试着收板框，给用户看收之前和之后的尺寸，让用户选。板框一变，安装孔和叠板的另一块板要跟着核对。
- **太挤时给选项，不硬挤：** A 小阻容放到底面；B 某个芯片放到底面；C 放大板框。说清代价：底面有件就是双面贴片，贴片费更高，手焊要翻面。
- **电感、开关电源**：电感本体下方各层不走线、不铺铜（地层保留）；开关节点铜面积小；输入电容、芯片、电感、输出电容围成的回路尽量小。
- **芯片的散热焊盘和散热孔网络设成 GND**（规格里把散热焊盘接地），否则打上去的孔会报错。
- **大电流路径直而短**：电池 → 开关 → 驱动 → 电机接口按顺序排成一条线。
- **四层板、内层按电源分区时，布局阶段就画分区。** 每路电源的大电流焊盘和插件电源脚都要落在自己的分区里。把分区写进 `[boards.<板>.planes]`，用 `python <ROOT>/kit/route/plane_board.py <dump>` 检查每个区是不是一整块。

## 按飞线优化（布线前必做，不用等用户说）

```bash
python <ROOT>/kit/dump.py layout.json
python <ROOT>/kit/pcb/ratsnest.py layout.json --png rats.png
```

报告给出飞线总长、交叉数、交叉最多的元件和网络、最密的格子。图上红线是交叉 3 次以上的飞线。

逐项处理，每改一处重新跑一次，**交叉数降了才保留**：

1. **交叉最多的元件**：转 90° / 180°，或和邻近的件换位。
2. **芯片方向**：看每个脚的线往哪边走。一排脚的去向和芯片朝向相反时，转过来或放到底面（镜像后方向正好对）。
3. **引脚顺序造成的交叉**：对调等价引脚（同一组 GPIO、同一定时器的通道、IO 扩展的口）。这要改原理图和固件，**先问用户**。
4. **连接器的针序和去向**：同一个连接器上的信号去板子两头时，考虑拆成两个座，或者挪到两头之间。
5. **挡住出线口的小件**：去耦电容、上拉电阻不要堵在芯片出线多的一侧。

降到再改也不明显下降为止，把优化前后的数字和图一起给用户（停点 S4）。

飞线报告只能粗筛：直线飞线穿过电感禁布区、穿过一排焊盘，实际走线都会绕开。它用来排除明显差的摆法，最后以实际布线为准。

想用 `pcb auto-place` 做种子：只能经 `python <ROOT>/kit/pcb/guard.py place auto-place`，结果变差会自动撤销。

## 布线阶段退回来时

布线器报 `STALL` 或 `no path`，或一轮跑了 40 分钟以上还不收敛，就回到这里：看卡住的网在哪、被什么挡着，按上面的办法改布局，再去布线。不要靠调布线参数硬撑。

## 用户微调之后

用户会在 EDA 里自己挪件。之后以 EDA 为准：`python <ROOT>/kit/dump.py` 存一份快照，把坐标并回坐标表，再继续。

## 过关

- 无出界、不压安装孔；重叠项看过；密集处焊盘之间不重叠（库里的封装会更新，焊盘可能变大）；
- 飞线报告做过，交叉数不再明显下降；
- 四层分区板：`plane_board.py` 每个区一整块、插件电源脚都在区内；
- 「四个目标」（`pcb-workflow`）对照过：测试点和调试口够得着、不被挡；元件对齐同向；去耦和电源回路到位；接口防呆、安装孔留了禁布；
- 用户看过布局图，确认了接口朝向、操作件位置、板框尺寸。

过关后转到 `pcb-routing`。
