# 阶段 1–2：需求、方案、选型、引脚

先读 `pcb-workflow` 技能里的硬规则和协作规矩（本次会话读过就不用再读）。`ROOT` = 本文件所在目录的上两级。
详细方法：`ROOT/docs/01_需求与方案.md`、`ROOT/docs/02_选型与引脚.md`。

## 阶段 1：需求与方案

### 做法

1. **先收集，再提问。** 读用户给的所有东西：题目、旧板的原理图和 PCB、现有模块、机械模型。旧板是最好的需求来源，逐块看它有什么功能、哪里出过问题。
2. **写需求文档**（模板 `ROOT/templates/requirements.md`），每条功能编号、分级、写验收方法：
   - **P0 必须 / P1 应该 / P2 可选**，把必须实现的和可以实现的分开；
   - 机械：板子尺寸、安装孔坐标和孔径、叠板方式、每个接口从哪一边插拔、限高；
   - 电源：输入范围、每路电压和**最大电流**、保护；
   - 接口：每个连接器的型号、针数、针序、对端。
3. **出一份待定项清单**，每项都是选择题（2–3 个选项、推荐项、代价）。用户回答后把文档版本号加一。
4. **先定电源架构**，再定别的。画电源树，每个节点写电流预算；线宽和过孔数量从这里来（1 oz 外层：3 A 约 1.2 mm，1 A 约 0.5 mm；一个 0.3 mm 孔按 1 A 算）。
5. **动手画图之前，把需求逐条和用户核对一遍**（停点 S1）。
6. **补上用户通常不会主动提的需求**，写成 P0/P1 条目让用户确认：
   - 好测试：每路电源和关键信号（总线、使能、复位、驱动输入）有测试点和地夹持点；调试口（SWD、串口）在板边；每块板能单独上电；各路电源之间留跳线或 0 Ω，每路一个指示灯。
   - 皮实：输入防反接、保险、TVS；对外接口 ESD 或限流、防呆；复位、启动模式、使能、驱动输入有上下拉（主控没上电或在复位时电机不乱转）；器件的电压、电流、温度留余量。

### 这些事要主动问（用户不会想到要先说）

- 哪些总线和接口要**全部引出**（I2C、串口、SPI、空闲 GPIO）？各要几个座？
- 外接传感器、执行器的接口数量是硬性要求还是尽量多？必须在板边吗？
- 板上有哪些**要用手操作、用眼看**的件（旋钮、按键、拨杆、屏幕、指示灯）？怎么拿着板子用？
- 板子装在哪：安装孔位置是否要和别的板、底盘对齐？
- 旧板的尺寸要不要沿用？（用户可能说「不用量旧的，直接重新设计」）

### 多块板

- **先做能单独上电测试的那块**（通常是主控板）。先做驱动板、电源板，会出现做完没法测的情况。
- 两块板的板框、安装孔、叠板连接器位置一起定，安装孔要对齐。
- 叠板连接器从一开始就定好谁在底面：底面排针是镜像的，原理图里要奇偶对调（1↔2、3↔4…）。

### 用户改主意时

需求变了（换主控、砍功能、加接口）是正常的。做法：更新需求文档和版本号 → 重排引脚表并自检 → 列出要删、要加的元件 → 告诉用户哪些已完成的工作要重做。不要在旧方案上打补丁。

### 过关

- 每条 P0/P1 都有验收方法；
- 上面第 6 步的测试和保护条目用户确认过；
- 尺寸、孔位、接口朝向、电源树（含电流）用户确认过；
- 文档末尾的「决策记录」列出了用户的每个选择。

## 阶段 2：选型与引脚

### 选型

```bash
easyeda lib search --query "TPS54560"          # 按型号搜
easyeda lib by-lcsc --lcsc C123456,C789012     # LCSC 编号 -> 库里的器件
```

- 每个器件落到一个 LCSC 料号：有库、有货、封装能贴或能手焊。优先嘉立创基础库。
- 规格里写 `lcsc`，或 `lib` + `uuid`；`uuid` 必须是**器件** UUID，不是符号 UUID。
- 关键器件（主控或核心板、电源芯片、驱动芯片、连接器）列成表给用户确认，每个带一个备选。

### 引脚表

写成代码（模板 `ROOT/templates/pinmap_template.py`），每次改完自动检查：

- 0 重复引脚；每个信号用的脚确实有这个外设功能；
- 外部中断线不冲突；下载口和板载占用的脚不分配；
- 核心板插座的针位和实物一致（用核心板底面视图核对）。

同一份代码生成三样东西：给人看的表、给固件的头文件、给原理图规格的 JSON。

板子密、飞线乱时，做一次换脚优化（`docs/02` 的「进阶」一节）：在外设功能不变的前提下交换等价引脚，把飞线交叉数降下来。示例板交叉数 871 → 371，过孔 431 → 251。

### 过关

- 引脚表自检全过；
- 关键器件用户确认过；
- 所有元件都有 `lcsc` 或 `lib` + `uuid`。

过关后转到 `pcb-schematic`。
